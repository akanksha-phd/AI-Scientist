# Neural Network Classification with PyTorch

## Objective

Build a simple neural network for binary classification and understand the basic deep-learning workflow.

## Architecture

4 input features → 16 hidden units → ReLU → 8 hidden units → ReLU → 2 output classes

## Concepts Practiced

- Hidden layers
- ReLU activation
- Logits
- CrossEntropyLoss
- Adam optimizer
- Training loops
- Classification
- Softmax probabilities
- Model evaluation
- Generalization

## Key Takeaway

Neural networks use hidden layers and nonlinear activation functions to learn complex patterns from input features.

For classification, the model produces logits, which can be converted into probabilities using Softmax.
